## 笔记编写原则

- **原理优先**：不仅记录如何使用，更说明为什么这样设计。
- **工程导向**：记录适用场景、异常处理、性能与安全边界。
- **可复现**：示例附环境、运行步骤和结果验证方式。
- **出处明确**：优先引用论文、官方文档与开源仓库，并标注来源。
- **持续迭代**：学习笔记与面试专题持续更新。

## 学习阶段

1. LLM 基础：Transformer、Token、推理、结构化输出。
2. Agent 核心：Agent Loop、ReAct、Planning、Workflow、状态管理。
3. 能力增强：工具调用、MCP、Skills、RAG、Memory。
4. 企业工程化：多 Agent、任务可靠执行、评估、安全、部署。
5. 综合实践：项目复盘、性能指标与高频面试问题。
